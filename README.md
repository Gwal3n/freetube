# FreeTube

A personal fork of [leshkodev/freetube](https://github.com/leshkodev/freetube), inspired by [NewPipe](https://github.com/TeamNewPipe/NewPipe). Watch YouTube without signing in, with subscriptions, history, and playlists kept on your device.

Built for personal sideloading.

## Build

Open `FreeTube/FreeTube.xcodeproj` in Xcode, choose a signing team, and build for iOS 17 or later.

## Credits

Thanks to Leshko for the original app. FreeTube uses [b5i/YouTubeKit](https://github.com/b5i/YouTubeKit) for YouTube data and a modified copy of [alexeichhorn/YouTubeKit](https://github.com/alexeichhorn/YouTubeKit) for stream extraction. Download support also draws on [yt-dlp](https://github.com/yt-dlp/yt-dlp) through [YoutubeDL-iOS](https://github.com/kewlbear/YoutubeDL-iOS).
